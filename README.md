# Homebrew tap for Serein

Homebrew tap for [Serein](https://github.com/ViceVerse-cz/Serein), an unofficial native
Rust/egui client for existing Discord accounts.

```sh
brew tap ViceVerse-cz/serein
brew install --cask serein
```

Or in one step:

```sh
brew install --cask ViceVerse-cz/serein/serein
```

Requires Apple Silicon and macOS Sonoma or newer.

`Casks/serein.rb` is updated automatically by the Serein release workflow. Do not edit it
by hand; report problems in the [Serein repository](https://github.com/ViceVerse-cz/Serein/issues).
